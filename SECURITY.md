# Security policy / Politique de sécurité

Ce composant analyse des fichiers 3D potentiellement non fiables dans un processus de l'Explorateur (`dllhost.exe`).
This component parses potentially untrusted 3D files inside a shell host process (`dllhost.exe`).

**Signaler une vulnérabilité / Report a vulnerability** : utilisez *Security → Report a vulnerability* sur GitHub
(rapport privé) plutôt qu'un ticket public. Please use GitHub's private vulnerability reporting rather than a public issue.

Les fichiers qui provoquent un plantage ou une consommation mémoire excessive sont considérés comme des bugs de sécurité.
Crashes or excessive memory use triggered by a crafted file are treated as security bugs.
